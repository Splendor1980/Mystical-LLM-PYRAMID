# tokenizer/

`tokenizer.json` — словарь модели: **3000 BPE-токенов**, нормализация **NFKC**,
**ByteLevel** pre-tokenizer/decoder (конфиг, идентичный классическому `tokenizers`).

Специальные токены: `<pad>=0 <unk>=1 <bos>=2 <eos>=3`.

Особенности:

- В словаре **нет символа `?`** и ряда пунктуации (`! ; % — “ ” ‘ ’`) —
  такие символы кодируются как `<unk>` (по одному на символ). Поэтому вопросы
  в промпте пишутся без вопросительного знака; `…` NFKC-сворачивается в `...`.
- Словарь выбирался по принципу «один мастер-словарь 3000»: высокая утилизация
  эмбеддингов для 11M (≈66% против ~40–45% у альтернативного словаря 5483).
- Режимы длины: промпт < 128 токенов дополняется слева до кратного 128 (требование
  чанковой рекурренции RWKV).

Загрузка (Python):

```python
from tokenizers import Tokenizer
tok = Tokenizer.from_file("tokenizer/tokenizer.json")
```
