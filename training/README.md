# training/

Код обучения и экспорта «Мистики» (RWKV-5.2, 11M). Корпусы сюда не включены —
все скрипты воспроизводят данные и обучение с нуля.

| Файл | Что делает |
|---|---|
| `rwkv_model.py` | архитектура модели (слой «x051a», per-head time-decay, PreLN/GroupNorm, tied эмбеддинг) |
| `train_mystic.py` | трейнер: фазы A (претрейн) / B (SFT) / C (дошивка), eval + samples, resume, чекпойнты |
| `kernel_main.py` | рантайм для Kaggle (поиск данных, резюм со свежего чекпойнта) |
| `build_kernel.py` | конкатенация скриптов в единый самодостаточный Kaggle-kernel |
| `build_data_bundle.py` | сборка папки-датасета (narr/qa бины, tokenizer, prompts, отчёт) |
| `kernel-metadata.json` | метаданные Kaggle (GPU T4) |
| `export_app_model.py` | экспорт в `model.bin` (fp16) + рекуррентный эталон для верификации порта |
| `fix_bytemap.py` | регенерация bytemap токенизатора (эмпирически восстановленный) |
| `tok_battery.py`, `tok_decode_probe.py` | эталонные батареи токенизатора/декодера |
| `gen_ref.py`, `gen_check.py` | генерация-эталон и проверка сэмплинга |

## Обучение (кратко)

- **Конфигурация**: vocab 3000, ctx 512, 13 слоёв × 256 × 8 голов (~11.03M парам.).
- **Претрейн (A)**: 1 эпоха ≈227.19M токенов (нарратив 219.7M + Q&A 7.5M, 3.3%),
  LR 2e-4 → 3e-5, warmup 1.5%, dropout 0.02.
- **SFT (B)**: 3 эпохи только Q&A (7.5M токенов, пары ×8 повторов), LR 5e-5 → 1e-5,
  dropout 0.05.
- **Дошивка (C)**: 0.5 эпохи 90/10 нарратив/Q&A.
- **Железо**: Kaggle T4, bf16 autocast, ~16.3k ток/с; итого 6.4 ч, 22 179 итераций.
- **Итог**: `best_val = 0.1638` (PPL ≈ 1.18), train-loss в хвосте ~0.11–0.15.

## Известные грабли

1. Промпт короче 128 токенов валил forward — добавить/обрезать до кратного 128
   в `generate()`.
2. `pip install -U kaggle` в контейнере ломит `datasets version` (400) — не ставить.
3. Чекпойнты обязательно в облако: 12-часовая сессия может оборваться.
